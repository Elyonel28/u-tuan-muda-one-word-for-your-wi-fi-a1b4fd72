One word for your Wi-Fi: **Cliffhanger**.

Home Wi-Fi always dies right at the cliffhanger — the screen freezes a
second before the reveal, every single time. It is funny because it is
true, and it works as a network name on its own.

## Run it

```sh
node main.ts
```

The program writes the single word to `/output/entry.txt` (11 characters,
inside the bounty's 1–20 character gate). Set `OUTPUT_DIR` to write
somewhere else, for example `OUTPUT_DIR=./output node main.ts`.
